# Battle Pass

Seasonal reward track accessed from the Daily Rewards / Great Value screen (Battle Pass tab).

## Structure

- **Season length:** 28 days per pass
- **Three reward tracks** (3 columns: blue / purple / orange):
  - **Free** — available to all players
  - **Advanced Pass** — paid tier
  - **Luxury Pass** — top paid tier
- After the current Pass ends, the next one becomes available

## How you progress

Complete Daily Tasks to earn activity points (XP). Each level on the pass unlocks rewards in each of the three tracks the player has access to.

## EXP Carryover (end of season)

At the end of each season, EXP carries over to the next pass based on total EXP earned:

| EXP earned | Carried over |
|---|---|
| < 1,450 | 0 |
| 1,450 – 1,699 | 200 |
| 1,700 – 1,949 | 300 |
| 1,950 – 2,199 | 450 |
| 2,200 – 2,449 | 550 |
| ≥ 2,450 | 700 |

## Extra rewards (post-cap)

Once the Pass reaches max level, every additional **50 activity points** earned grants **1 Gray Key** (used for Silver Chest pulls). This continues until you hit the season cap of **20 gray keys**. After that, additional activity points earn no further reward for the season.

## "Claim All" button

A bulk claim button at the bottom of the Battle Pass screen claims every unclaimed reward across the tracks the player has access to.
