These shops sit alongside Guild Store, Guild Expedition Shop, and Arena Shop in the **bottom-tab shop carousel** accessible from the Guild Store / Arena Shop / Skin Exchange Shop screens. Each is event- or skin-system-specific.

The full bottom-tab order (left to right):

## 1. Event Shop

The Event Shop is a **multi-event vendor** with multiple top-level tabs (one per active or recurring event). Each tab houses milestone-gated stocks.

### Sub-tabs observed

- **Island Store** (current — Island Treasure Hunt event)
- **Darksurge Vault** (separate event tab)

### Currencies

The Event Shop accepts event-specific tokens (different per tab). For Island Store, costs are denominated in a yellow-icon currency (Island Tokens) — cost values like 2, 5, 10, 11, 12 visible per item.

## 2. Skin Exchange Shop

The Skin Exchange Shop is the dedicated vendor for weapon skins — both buying new skins and exchanging for upgraded variants.

## Strategic guidance (for the bot)

- **Active event participation is the primary path to Legendary hero shards** (Otta, Thor, Cleo, etc.) — Guild Store only stocks Rare. Track Island Treasure Hunt and similar events when they're live.
- **Milestone progression in Event Shops** is high-leverage — pushing Island Points to 200K / 300K / 400K unlocks tiered rewards each event. Plan participation to clear the highest tier you can reach.
- **Skin Exchange Shop limits are per-event-cycle** (Purchases left: 6 fixed) — prioritize the highest-value skins for your set/build first since you can't re-buy after the limit.
- The cost-12 skin tier in Hero Skin Shop appears to be higher rarity than the cost-6 tier — pay attention to icon background colors for rarity tiering.
